# JOON GYRO LAB v0.1.3

아이폰 가로모드 PWA 자이로스코프 조작 검증용 독립 앱입니다. Canvas 2D 의사-3D 프로토타입입니다.

## 실행
1. GitHub Pages를 main / root로 설정.
2. 아이폰 Safari에서 HTTPS 주소 접속.
3. 가로로 잡은 뒤 센서 시작 → 권한 허용 → 중립 보정.
4. 앞뒤/좌우 센서 반응을 확인하고 설정에서 민감도와 반전을 조절.

현재 센서 축은 아이폰 실기기 검증 전입니다.

## v0.1.1
- 기본 민감도 0.6, 데드존 5°, 최대 입력 약 35°, 차체 시각 기울기 최대 25°
- 스무딩 추가 및 좌우 이동 약화. 중립시 속도 유지, 자동 출발 후 가감속 개별 제어.
- 화면 회전 시 중립 보정. 가능한 경우 화면 방향 잠금 시도(아이폰 Safari에서는 거부될 수 있음).
- 기존 v0.1.0 설정은 새 기본값으로 초기화, 사용자가 새로 조절한 설정은 유지.
